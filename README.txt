ABM — MORE THAN A SECTION
===========================

A responsive interactive digital yearbook / memory website built with:
- HTML
- CSS
- Vanilla JavaScript

No database, PHP, framework, or installation is required.

RUN:
1. Extract the ZIP.
2. Open index.html directly, or use VS Code + Live Server.
3. For XAMPP, copy the folder to C:\xampp\htdocs\ and open:
   http://localhost/ABM-Class-Memories/

PERSONALIZE:
- Put your class photo in images/class.jpg
- Put gallery photos in images/memory01.jpg through memory06.jpg
- Put people photos in images/ through 
- Edit names, captions, timeline text, and descriptions in index.html.
- Add more gallery cards by copying a memory-card block.
- The "Guess Who?" section currently uses .
- The random memory messages are in script.js.

SUPPORTED IMAGE TYPES:
The included file names use .jpg, but you can change the src extensions to .png or .webp if desired.

FEATURES:
- Responsive desktop/tablet/mobile layout
- Scroll reveal animations
- Custom desktop cursor
- Animated photo gallery modal
- Keyboard arrows in gallery
- Guess Who interaction
- Random memory generator
- Hidden surprise buttons
- Final reveal animation
- Progress bar
- Placeholder images if your real photos are missing

TIP:
For a real class archive, resize very large photos before adding them. Around 1600–2400px wide is usually enough for a website and keeps loading faster.
